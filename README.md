### settings
- go to https://github.com/settings/appearance and select your theme there

### installation
- coming soon on the chrome web store + hosted editor/theme store on gitstyles.ryanaque.com

### local/dev installation
- clone the repository
```
git clone https://github.com/maytcha/gitstyles.git
```
- visit `chrome://extensions/`
- enable on developer mode on the top right
- open the git repository folder
